# Bingo Multiplayer Online

A Next.js multiplayer game lobby with two games:

- Bingo
- Guess Word

Live site: [bingo-multiplayer-online.vercel.app](https://bingo-multiplayer-online.vercel.app)

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Games

- `/bingo` - create or join a two-player Bingo lobby.
- `/guess-word` - one player guesses the secret word while the other answers yes, no, or maybe.

## Build

```bash
npm run build
```
